# Sub-Phase 2.4: Denial, Rebuttal & Legal Appeal Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the Carmack Amendment statutory lawsuit deadline engine (`lawsuit_deadline_at = denial_date + relativedelta(years=2, days=1)`), pre-packaged legal rebuttal generators targeting carrier denial pretexts (concealed damage, salvage duty, packaging negligence), and rebuttal submission guards.

**Architecture:**
1. Carmack statutory lawsuit deadline service (`apps/api/app/services/carmack_lawsuit_service.py`) computing exact 2-year + 1-day lawsuit clocks across leap years and month boundaries using `dateutil.relativedelta`.
2. Rebuttal generation service (`apps/api/app/services/rebuttal_service.py`) compiling evidence-backed rebuttal demand packets.
3. REST API router endpoints in `apps/api/routers/claims.py` providing rebuttal generation and submission guards.
4. Comprehensive TDD test suite (`apps/api/tests/test_rebuttal_engine.py`) verifying lawsuit deadline arithmetic, leap-year calculations, and evidence citations.

**Tech Stack:** Python 3.11/3.14, FastAPI, SQLAlchemy, Alembic, `python-dateutil`.

---

## Global Constraints

- Lawsuit deadline MUST be calculated using `dateutil.relativedelta(years=2, days=1)`.
- Rebuttal demand packages MUST cite clean BOL origin receipt notations, photo evidence, and 49 U.S.C. § 14706.
